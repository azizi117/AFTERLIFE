AFTERLIFE — نسخه شروع پروژه TON

ویژگی‌های فعلی:
- مینی‌اپ تلگرام با ظاهر مشکی و طلایی
- استخراج هر ۲۴ ساعت، ۱۰۰ واحد AFT
- ذخیره موجودی در SQLite روی سرور
- اعتبارسنجی initData تلگرام در سمت سرور
- ثبت تعداد دعوت‌ها و پاداش ۵ واحدی برای معرف هنگام اولین استخراج دعوت‌شده
- جایگاه آماده برای اتصال کیف پول TON در مرحله بعد

مهم:
AFT در این نسخه فقط امتیاز داخل برنامه است؛ توکن بلاکچینی نیست.
فعلاً هیچ برداشت، واریز، اتصال کیف پول یا قرارداد هوشمندی فعال نیست.
برای توکن واقعی باید قرارداد Jetton روی TON جداگانه ساخته، بررسی و منتشر شود.
هیچ‌وقت BOT_TOKEN را داخل فایل‌های عمومی یا چت قرار ندهید.

راه‌اندازی:
1) Node.js نسخه 20 یا جدیدتر نصب باشد.
2) در پوشه پروژه دستور npm install را اجرا کنید.
3) متغیر محیطی BOT_TOKEN را با توکن تازه BotFather تنظیم کنید.
   Linux/macOS: export BOT_TOKEN="توکن"
   PowerShell: $env:BOT_TOKEN="توکن"
4) دستور npm start را اجرا کنید.
5) آدرس HTTPS سرور را در BotFather > Bot Settings > Menu Button قرار دهید.

نکته میزبانی:
این پروژه به هاست Node.js پایدار با فضای ذخیره‌سازی پایدار نیاز دارد.
هاست استاتیک Ship.page به‌تنهایی برای اجرای server.js و پایگاه داده کافی نیست.
در محیط واقعی HTTPS ضروری است.
نام کاربری ربات را در تنظیمات BotFather مطابق ربات خودتان قرار دهید.
